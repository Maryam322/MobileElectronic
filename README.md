#  MobileElectronic – E-Commerce Store

**MobileElectronic** is a Django-based e-commerce web application for browsing and purchasing mobile phones and electronic products. It includes product management, shopping cart functionality, order processing, and a responsive user interface.

##  Features

*  Mobile & Electronics Product Listings
*  Product Search & Browsing
*  Shopping Cart
*  Order Management
*  User Authentication
*  Admin Product Management
*  Product Pricing & Inventory
* Responsive UI

##  Tech Stack

* **Backend:** Python, Django
* **Frontend:** HTML, CSS, Bootstrap
* **Database:** SQLite
* **Templates:** Django Templates
* **Icons:** Bootstrap Icons

##  Installation

Clone the repository:

```bash
git clone https://github.com/Maryam322/MobileElectronic.git
cd MobileElectronic
```

Extract the project ZIP and navigate to the Django project directory.

Create a virtual environment:

```bash
python -m venv venv
venv\Scripts\activate
```

Install dependencies:

```bash
pip install -r reqiurement.txt
```

Run migrations:

```bash
python manage.py migrate
```

Start the development server:

```bash
python manage.py runserver
```

Open:

```text
http://127.0.0.1:8000/
```
